# ASCII 🎄 圣诞树

树、星星、礼物、树干树根、飘雪与祝福语全部由 ASCII 字符组成，
在浏览器里实时做 3D 旋转 + 逐字符光照，带金色螺旋灯带、泛光与闪烁。

## 文件

- `index.html` — 可编辑的单文件网页（无外部依赖，双击即可打开）
- `ascii-xmas-tree.mp4` — 20 秒竖版成片，1080×1920，30fps

## 网页里的可调参数

打开 `index.html`，顶部 `CONFIG` 集中了所有可调项：

| 参数 | 作用 |
| --- | --- |
| `canvas` / `grid.cols` | 画布尺寸与字符列数（列数越大越细腻） |
| `time.spinTurns` | 20 秒内转几圈 |
| `tree.hueTop` / `hueBottom` | 树冠由顶到根的色相范围（黄绿 → 青绿） |
| `tree.sat` / `lightMin` / `lightMax` | 树冠饱和度与明度 |
| `band` | 金色螺旋灯带：圈数、点数、亮度 |
| `star` | 顶部星星大小、厚度、金光 |
| `gifts` | 树下 5 个礼物的位置、颜色 |
| `trunk` / `root` | 树干与树根 |
| `snow.count` | 雪花数量 |
| `bloom` | 泛光强度（两层模糊） |
| `greet` | 底部祝福语文案与位置 |

改完保存、刷新浏览器即可看到效果。

## 操作

- 空格键或点击画面：暂停 / 继续
- 加 `?record=1` 打开录制模式：`window.__renderAt(秒)` 精确渲染任意时刻
- 加 `?still=9.5` 直接渲染某一秒的静帧
